Run the ForgeVigil demo

Reproduce the recorded policy decisions locally using fictional requests and a fixture assessor.

Run it locally

You’ll need Git and Python 3.11–3.13. The demo uses the Python standard library and temporary local state. It makes zero model calls and requires no API key.

  1. Clone the source and check out the recorded revision. 
    git clone https://github.com/billyrdavis1985-bot/ForgeVigil.git
cd ForgeVigil
git checkout --detach fc771b36b16a49915c07891673fc4bc5ead9b3c8
  2. Run the fixture demo from the repository root. 
    python3 -B -m forge_vigil demo --assessor fixture --review

    On Windows, use py -3 in place of python3 if you use the Python launcher.

Compare your result

DENY · HTTP 403

REVIEW · HTTP 202
The request with unverified approval waited for an operator decision.
Replay

Scripted operator release

Final check
Expect two outbox items containing only approved public-spec bytes, zero model calls, exit code 0, and RESULT: PASS.

Timestamps and generated effect IDs can vary. Compare the decisions and final checks.
